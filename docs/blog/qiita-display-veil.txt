## 映画を見ていると、隣のディスプレイがまぶしい

マルチディスプレイで映画や動画を見るとき、再生していない画面にブラウザーや作業用アプリが表示されたままだと、その明るさが気になることがあります。

そんなときに使うための Windows 向けフリーソフト、**Display Veil** を作りました。鑑賞する画面を1台選び、ほかのディスプレイを黒いウィンドウで覆うアプリです。

![Display Veil の使用前と使用中。鑑賞画面はそのまま、ほかの画面を黒幕で覆う][overview]

Windows の「メインディスプレイ」を変更する必要はありません。普段のメイン画面はそのままに、映画を流している別の画面を鑑賞用として選べます。

**MITライセンスで公開しており、無料で利用できます。インストールや管理者権限も不要です。**

- [ダウンロード：GitHub Releases](https://github.com/check5004/DisplayVeil/releases)
- [ソースコード・README](https://github.com/check5004/DisplayVeil)

## 使い方は、画面を選んで開始するだけ

### 1. ZIP を展開して起動

GitHub Releases の Assets にある `DisplayVeil-<バージョン>-win.zip` をダウンロードし、「すべて展開」して `DisplayVeil/DisplayVeil.exe` を開きます。フォルダー内の `DisplayVeil.exe.config` も一緒に置いてください。

| 項目 | 必要な環境 |
|---|---|
| OS | Windows 10 / 11 |
| ランタイム | .NET Framework 4.8 以降 |
| ディスプレイ | 2台以上を Windows の「拡張」表示で接続 |
| インストール・管理者権限 | 不要 |

:::note info
GitHub が表示する `Source code (zip)` はソースコードです。ビルド済みアプリを使う場合は、Assets の `DisplayVeil-<バージョン>-win.zip` を選んでください。
:::

### 2. 映画を見る画面を選ぶ

起動すると、接続されているディスプレイの配置図と一覧が表示されます。

![Display Veil の設定画面。4台の画面配置と鑑賞画面の選択、自動復帰やショートカットの設定][screenshot]

「画面番号を表示」を押すと、実際の画面に番号が出ます。配置図と照らし合わせ、映画を見る画面をクリックして選びます。番号はこのアプリ内の番号です。

スクリーンショットは4台を接続した例です。冒頭の図解は3台ですが、3台専用・4台専用というわけではありません。Windows が拡張デスクトップとして認識する画面を対象にし、アプリ側で台数の固定上限は設けていません。

### 3. 「鑑賞をはじめる」を押す

設定画面が隠れ、選んだ画面以外に黒幕が表示されます。映画や動画は、普段使っているプレイヤーやブラウザーで再生してください。Display Veil が担当するのは、周りの画面を覆う部分です。

## 黒くした画面も、必要なときだけ操作できる

鑑賞中でも、別の画面で少し調べものをしたり、作業用アプリを確認したりしたいことがあります。そのたびにすべて解除しなくても、**操作したい画面の黒幕をダブルクリック**すれば、その画面だけ一時的に表示できます。

![黒幕をダブルクリックして一時操作し、マウスが画面から離れると1.5秒後に黒く戻る流れ][controls]

初期設定では、操作していた画面からマウスが離れると、1.5秒後に黒幕に戻ります。マウスを動かしただけでは黒幕は開かないので、画面を横切っただけで裏のアプリが表示されることはありません。

| こんなとき | 操作 |
|---|---|
| 少しだけ別画面を使いたい | 黒幕をダブルクリック。または操作案内の「この画面を操作」 |
| キーボードで作業を続けたい | 一時表示中の上部バーで「固定する」 |
| 自分のタイミングで黒く戻したい | 上部バーの「暗く戻す」 |
| すべての黒幕を外したい | 黒幕を右クリックして「すべて解除」。上部バーの「全解除」でも可能 |
| 鑑賞画面を選び直したい | 通知領域のアイコンをダブルクリック。または exe をもう一度起動 |

「固定する」を使うと、マウスが離れても表示を維持できます。また、ドラッグ中は自動で黒幕に戻りません。自動復帰そのものを設定でオフにすることもできます。

### キーボードからも切り替えられます

| 初期ショートカット | 操作 |
|---|---|
| `Ctrl + Alt + Shift + F9` | 開始 / 全解除 |
| `Ctrl + Alt + Shift + F10` | マウスがある画面を一時表示 / 黒く戻す |
| `Ctrl + Alt + Shift + F11` | 全解除のみ |

各キーは設定画面で変更・無効化できます。Windows へのグローバルキー登録が競合した場合は設定画面に表示されます。鑑賞画面で画面開閉キーを使っても、鑑賞画面を覆うことはありません。

全解除後もアプリは通知領域に残ります。完全に終了するときは、設定画面の × またはトレイメニューの「Display Veil を終了」を使います。

## どういう仕組みで作ったか

実装は **C# / .NET Framework 4.8 / Windows Forms** です。Windows が列挙したディスプレイから鑑賞画面を除外し、残りの画面の位置と大きさに合わせて黒いウィンドウを置いています。

操作感のために、次の点を工夫しています。

- **黒幕の操作で映画側のフォーカスを奪わない。** 黒幕と操作バーに `WS_EX_NOACTIVATE` を使い、表示や配置でもアクティブ化を避けています。裏のアプリを実際にクリックした場合は、そのアプリにフォーカスが移ります。
- **一時表示と固定表示を分ける。** 「黒幕」「一時表示」「固定表示」の状態を画面ごとに管理します。マウスが離れたときの自動復帰は一時表示だけに適用し、待ち時間には `Stopwatch` を使っています。
- **画面構成が変わったら全解除する。** 接続・解像度・拡大率などが変わったときは、一度黒幕を解除します。鑑賞画面を確認してから再開する流れです。

更新確認でGitHub APIへ通信します。自動確認は設定でオフにできます。テレメトリ・常駐サービスはありません。設定は `%LOCALAPPDATA%\DisplayVeil\settings.json` に保存します。

<details><summary>ソースからビルドする場合</summary>

リポジトリを取得し、プロジェクト直下で実行します。

```powershell
.\build.ps1 -Test
```

`artifacts/DisplayVeil/DisplayVeil.exe` が生成されます。Windows の .NET Framework コンパイラーを使い、追加 SDK や NuGet は使いません。配布 ZIP も生成する場合は `-Package` を追加します。

</details>

## 使う前に知っておきたいこと

:::note info
黒幕はディスプレイの電源を切る機能ではありません。電源・輝度・配置は変更しないため、液晶ディスプレイではバックライトの光が残る場合があります。
:::

複製（ミラー）表示の物理画面を別々に黒くすることはできません。Windows の拡張表示で使用してください。

通常のデスクトップ上に最前面ウィンドウを表示する仕組みなので、UAC、ロック画面、排他的フルスクリーン、一部のシステム UI や他の最前面アプリなどを常に覆える保証はありません。画面の保護や情報漏洩防止を目的とした機能でもありません。

ロックやスリープ時には全解除し、起動・復帰時に自動で黒幕を表示することはありません。
