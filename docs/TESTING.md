# Display Veil テスト

## 実施済み

2026-09-06 / Windows / .NET Framework 4.8。

- 警告をエラーとして扱うビルド。
- `build.ps1 -Test` による自動テスト35件すべて成功。結果の一覧は実行時に標準出力へ表示。検証記録は `artifacts/test-results.txt`。
- 実機の4画面で物理座標と DPI の取得。現在の設定は 2560×1440 が2画面、2560×1080 が2画面、いずれも100%。
- 実機4画面それぞれで、黒幕の矩形が画面全体と厳密に一致すること。
- 黒幕表示・解除・操作バー表示がフォアグラウンドウィンドウを変更しないこと。
- 設定画面を Windows のUI自動化で起動・描画確認。
- 配置図で Windows メイン以外の画面2を選び、対象3画面の表示を確認して開始。
- 再度 exe を起動すると同じインスタンスで全解除・設定復帰すること。
- 設定画面の × でアプリが終了すること。
- 混在解像度・負座標・縦置き・129画面の模擬配置と、鑑賞画面の除外。
- 自動復帰・ピン・ポインター再進入・ドラッグの状態遷移。
- 設定の保存と上書き・古い設定・破損・書込失敗。
- 実際の RegisterHotKey による競合・重複・無効化・解放。
- 黒幕のダブルクリックが最後のマウスアップ後まで解除されないイベント順序。
- 100 / 125 / 150 / 200% の操作バー寸法と描画の確認。

黒幕はアプリ一覧に出ない非アクティブな補助ウィンドウのため、UI自動化ツールから直接クリックできなかった。
マウスでの一連の体験、動画プレイヤー固有の挙動、実際の拡大率変更・ケーブルの抜き差しは次のチェック項目で確認する。
自動テスト中は実際の画面に黒幕を短時間表示し、自動解除する。

## まず5分で確認

- [ ] `DisplayVeil.exe` を開き、「画面番号を表示」で配置と番号を照合する。
- [ ] Windows メイン以外の画面で動画を再生し、その画面を鑑賞用に選ぶ。
- [ ] 開始後、鑑賞画面は表示されたまま、ほかの3画面が端まで黒くなる。
- [ ] 動画の再生・音声が続く。別の画面の黒幕操作で再生が止まらない。
- [ ] 黒幕でマウスを動かすと案内が出て、停止後約2.5秒で消える。
- [ ] 黒い部分のダブルクリックで、その1画面だけが開く。裏のボタンが誤って押されない。
- [ ] 裏のアプリを操作し、マウスを鑑賞画面へ移すと約1.5秒で再び黒くなる。
- [ ] 「固定する」でマウスが離れても開いたままになる。「暗く戻す」で戻せる。
- [ ] Ctrl + Alt + Shift + F11 で全解除できる。

## 追加のUX確認

- [ ] 自動復帰までの1.5秒以内に戻ると、黒くならない。
- [ ] アプリのウィンドウをドラッグして別画面へ運んでいる間は、途中で黒くならない。
- [ ] 開いた画面で文字入力するときに固定を使えば、ポインターを別画面に置いても作業できる。
- [ ] 自動復帰をオフにすると、ピンを使わなくても開いたままになる。
- [ ] 案内をオフにしても、右クリックで「すべて解除」を表示できる。
- [ ] 右クリック後にマウスを動かさなくても、約2.5秒はボタンを押せる。
- [ ] F10 の画面開閉キーはポインターのある対象画面だけに効き、鑑賞画面には効かない。
- [ ] F9 を長押ししても連続で開閉しない。
- [ ] 操作バーの「全解除」、黒幕の「すべて解除」、トレイの全解除をそれぞれ確認する。
- [ ] 設定でキーを変更すると旧キーが解放され、新しいキーが動く。
- [ ] 同じキーを複数の操作に設定すると、重複の表示が出る。
- [ ] すべてのキーを無効化しても、マウスだけで開始・一時操作・全解除・終了できる。
- [ ] exe を再度開くと二重常駐せず、全解除して設定へ戻る。
- [ ] 最小化した設定をトレイから復帰できる。× で完全終了する。

## 画面構成・異常系

映画鑑賞をしていないときに確認してください。黒幕の全解除は F11、右クリック、exe 再起動から行えます。

- [ ] 3440×1440 のウルトラワイドを含む構成で、黒幕の上下左右に隙間がない。
- [ ] 100 / 125 / 150% を画面ごとに混在させても、黒幕・操作バーが欠けない。
- [ ] 設定画面を異なる拡大率のディスプレイへ移しても文字とボタンが使える。
- [ ] 画面を左側・上側・縦向きへ配置しても正しく覆う。
- [ ] 非鑑賞画面を抜くと全解除され、変更後の構成が表示される。
- [ ] 鑑賞画面を抜いた場合も全解除され、別の画面を無断で鑑賞対象にしない。
- [ ] 解像度や拡大率の変更後に、全解除して選択を確認できる。
- [ ] スリープ復帰・ロック解除後に勝手に黒くならない。
- [ ] 1画面構成では開始できず、案内が表示される。
- [ ] 複製表示は個別に覆えないことを確認し、拡張表示に戻す。
- [ ] 普段使う動画プレイヤーのフルスクリーン・HDR・通知の挙動を確認する。

## 再現情報

不具合が出たら「使用した操作」「各画面の解像度・拡大率・配置」「鑑賞画面の番号」「動画プレイヤー名」を記録すると調査しやすい。
アプリの画面番号は Windows の設定画面と一致する保証はない。「画面番号を表示」で確認する。
