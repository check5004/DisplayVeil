# Display Veil 設計

## 目的と操作の流れ

映画を再生する画面を明示的に 1 台選び、残りの拡張デスクトップを黒いウィンドウで覆う。
鑑賞画面と Windows のメイン画面は独立している。画面台数の固定上限は設けない。

起動時は全画面が通常表示のまま。選択を確認して開始すると設定ウィンドウが隠れ、通知領域に残る。
全解除だけでは常駐を終了せず、次回はホットキーで再開できる。× またはトレイの終了でプロセスも終了する。

## UXの判断

- マウス移動だけでは黒幕を開かない。通過や誤操作による明るい画面の点滅を避ける。
- 移動時の案内は 2.5 秒。必要なら設定で無効化できる。右クリックの操作案内は設定に関係なく利用できる。
- 黒幕全体のダブルクリックで、その画面だけを操作できる。ボタンを探さなくてもよい。
- ダブルクリックの最後のマウスアップ後、UIキューで非表示にする。裏へのクリック転送は行わない。
- 開いた画面からマウスが離れると 1.5 秒後に覆う。端の往復や誤移動には猶予を持たせる。
- マウスボタンを押している間は復帰カウントをリセットする。ウィンドウを別画面へドラッグする操作を妨げない。
- マウス位置とキーボード作業先が異なるときは「固定する」を利用する。キー入力の監視やグローバルフックは使わない。
- 操作バーは画面上部中央に置き、「固定」「暗く戻す」「全解除」を常に提供する。
- トレイが覆われても黒幕側のボタンから全解除できる。再度 exe を開く操作も全解除して設定へ戻る。

## 状態

アプリ全体は `待機 → 鑑賞中 → 待機`。鑑賞中は対象画面ごとに次の状態を持つ。

| 状態 | 黒幕 | 操作バー | 遷移 |
|---|---|---|---|
| Covered | 表示 | 非表示 | ダブルクリック / 操作ボタン / 画面開閉キー → Revealed |
| Revealed | 非表示 | 表示 | ポインター離脱 1.5 秒 / 暗く戻す / 画面開閉キー → Covered。固定 → Pinned |
| Pinned | 非表示 | 表示 | 固定解除 → Revealed。暗く戻す / 画面開閉キー → Covered |

全解除は全ウィンドウを破棄する。残ったピン状態を次回に引き継がない。
復帰タイマーには `Stopwatch` の単調増加時間を使い、時計合わせの影響を受けない。

## 技術構成

C# + .NET Framework 4.8 + Windows Forms。Windows 標準のコンパイラーでビルドし、追加 SDK・NuGet・WebView・サービスを不要とする。

| ソース | 責務 |
|---|---|
| `Core.cs` | 台数・配置の計算、鑑賞対象の除外、一時操作の状態遷移 |
| `Native.cs` | Win32 宣言、モニター列挙、物理座標・DPI・インターフェースID取得 |
| `Overlay.cs` | フォーカスを取得しない黒幕、操作バー、画面番号 |
| `MainForm.cs` | 日本語設定画面、配置図、スクロール可能な画面一覧、キー登録 |
| `AppController.cs` | ライフサイクル、通知領域、100msの状態更新、構成変更への対応 |
| `Settings.cs` | JSON設定の読込、初期値、原子的な保存、失敗通知 |
| `Program.cs` | 単一起動、既存インスタンスへの通知、例外時の全解除 |

## 複数画面とDPI

`EnumDisplayMonitors` + `GetMonitorInfo` でデスクトップの物理的な矩形を列挙する。
各画面の幅・高さ、負の原点をそのまま黒幕の境界に使い、作業領域だけでなくタスクバー領域まで覆う。
設定画面の配置図は全矩形の外接領域を同一比率で縮小する。

表示デバイスのインターフェースIDを選択保存に用いる。重複時はデバイス名を付加する。
ドライバー・接続ポートの変更などでIDが変わる場合は再選択が必要になる。見つからない選択をメイン画面へ自動置換しない。
ID取得不能時のデバイス名へのフォールバックは接続順の影響を受けるため、開始前の選択確認をUIに残す。
IDの取得方法は [EnumDisplayDevicesW の公式仕様](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-enumdisplaydevicesw) に従う。

manifest・アプリ設定・起動処理で Per-Monitor V2 を指定する。設定画面は Windows Forms の DPI スケーリングを利用し、
黒幕・操作バーは画面ごとの物理座標で配置する。操作バーのフォントは明示的なピクセル単位にし、二重スケーリングを避ける。
[Windows Forms の High DPI 設定](https://learn.microsoft.com/en-us/dotnet/desktop/winforms/high-dpi-support-in-windows-forms) を参照。

実機で確認できた拡大率は 100%。125 / 150 / 200% はレイアウトの自動検証を行うが、異なる拡大率の実画面間移動は実機チェック項目とする。

## フォーカスと重なり順

黒幕・操作バーは `WS_EX_NOACTIVATE`、`WS_EX_TOOLWINDOW`、`ShowWithoutActivation` を使用。
`WM_MOUSEACTIVATE` には `MA_NOACTIVATE` を返す。表示・再配置は `SetWindowPos` に `SWP_NOACTIVATE` を指定する。
フォーカスを移さない表示と最前面配置は [SetWindowPos の仕様](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowpos) に基づく。

黒幕自身は Alt+Tab・タスクバーの対象にしない。2 秒おきに最前面を再設定するが、マウスボタン押下中は行わない。
通常の最前面ウィンドウなので、システムUIや排他的フルスクリーンに対する完全な遮蔽は保証しない。
実機自動化ツールもこの種のウィンドウを対象一覧へ表示しないため、描画とイベント経路はアプリ内のテストで補う。

## ショートカット

初期値は Ctrl + Alt + Shift と F9 / F10 / F11。単純なキーや Windows キーは使用しない。
OS への登録成否を表示し、重複や競合した操作だけを無効にする。ほかの操作とマウス操作は利用できる。
`MOD_NOREPEAT` によって長押しの連続トグルを抑止する。F12 はデバッガー予約のため候補から除外する。
[RegisterHotKey の公式仕様](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey) を参照。

## 構成変更・異常時

- DisplaySettingsChanged と 2 秒ごとの構成比較を併用する。
- 画面の接続・解像度・DPI・作業領域・メイン指定の変更では全解除する。
- ロック・切断・スリープ・復帰時に全解除し、無断で再開しない。
- 作成途中の例外では、作成済みの黒幕も全解除する。UIイベントの例外でも最初に全解除する。
- プロセス終了で Windows がウィンドウを破棄する。画面設定自体を変えないため、復旧のための設定書き戻しは不要。
- 設定破損時は初期値で起動し、通知する。保存失敗時も現在の実行中の設定は有効。

## 更新確認

- `Updates.cs` が公開リリースAPIへの匿名GETとバージョン比較を担当する。正式版の `vMAJOR.MINOR.PATCH` と、対応する配布ZIPの公開を確認する。
- 本番の起動処理からUI表示後に非同期で確認する。自動確認は初期状態で有効。前回の試行時刻から24時間未満なら通信しない。時計が巻き戻った場合は確認を許可する。
- 成否にかかわらず試行時刻を保存し、失敗時の再起動による連続アクセスを抑える。手動確認は24時間制限と自動確認オフを無視する。同時リクエストは1本に制限する。
- 前回検出したタグを設定に保存し、新版が見つかっていれば次回起動でも表示する。通信失敗時は既知の更新リンクを保持する。
- タイムアウトは10秒、レスポンス上限は256KiB。終了時はキャンセルする。通信失敗は設定画面内に表示し、黒幕を解除したり鑑賞を中断したりしない。
- 通知は設定画面内だけに表示する。アプリの起動中に定期ポーリングはしない。リンク操作時だけブラウザーを開く。
- 開くURLは固定のGitHubリポジトリと検証済みタグから組み立てる。APIレスポンス内の任意URLは開かない。
- ダウンロード、インストール、ファイル交換、自動再起動は行わない。

## 範囲外

物理的な電源OFF、輝度変更、ミラー表示の分離、映像再生、メディアキー操作、Windows起動時の自動開始は行わない。
更新確認以外のネットワークアクセス・画面の録画・スクリーンショット収集・テレメトリは実装しない。
